# NOVA ENGINE 6 - Developer Tools

أدوات مساعدة داخل Unity Editor.

## النوافذ
- `Tools > NOVA > Project Validator`: فحص أولي لإعدادات المشروع.
- `Tools > NOVA > Project Setup Wizard`: إنشاء هيكل مجلدات داخل `Assets/NOVA`.

## معالج إعداد المشروع
يمكن اختيار المجلدات التي تريد إنشاؤها. لا يحذف المعالج ملفات موجودة ولا يستبدلها.

## إعداد Android
يعرض المعالج قائمة تحقق لإعداد Android. يجب تثبيت Android Build Support وSDK وNDK وOpenJDK من Unity Hub، ثم اختيار Android وضبط معرف التطبيق وإعدادات API.

## الحدود
هذه أدوات تنظيم وفحص فقط. لا تنفذ build، ولا تثبت وحدات Unity، ولا تضمن توافق التطبيق أو نجاح نشره.
