# NOVA ENGINE 6 — World Systems 0.6.0

حزمة أنظمة العالم لـ Unity 6، وتُضاف إلى مشروع Unity الحالي ولا تستبدل Unity.

## المحتويات
- **NovaDayNightCycle**: دورة ليل/نهار بتحريك ضوء الشمس وتغيير الإضاءة المحيطية.
- **NovaWeatherController**: حالات طقس أساسية (صحو، غائم، مطر، عاصفة، ثلج) مع ضباب وإضاءة وجزيئات اختيارية.
- **NovaProceduralSpawner**: توزيع Prefabs ببذرة ثابتة مع Raycast للعثور على الأرض.
- **NovaTerrainGenerator**: إنشاء Terrain من ضوضاء Perlin ببذرة قابلة للتغيير.
- **NovaChunkDistanceActivator**: تفعيل/إيقاف جذور المقاطع حسب المسافة.
- **NovaEnvironmentManager**: إعدادات الإضاءة المحيطية والضباب.
- **NovaWorldBootstrap**: رسالة تحقق عند بدء المشهد.

## التثبيت
1. فك ضغط الملف.
2. انسخ المجلد `Packages/com.nova.engine6.world` إلى مجلد `Packages` في مشروع Unity 6.
3. افتح المشروع وانتظر اكتمال استيراد السكربتات.
4. أضف المكونات المطلوبة إلى GameObjects من نافذة Inspector، ثم اربط المراجع (Sun، Player، Prefabs، Particle System).

## ملاحظات مهمة
- هذه نسخة تأسيسية قابلة للتوسعة، وليست محرك عالم كاملًا.
- تفعيل المقاطع هنا يعتمد على المسافة و`SetActive` فقط؛ ليس بثًا غير متزامن أو تحميلًا من القرص.
- الطقس مؤثرات أساسية، وليس محاكاة مناخية.
- مولّد التضاريس ينشئ Terrain جديدًا عند كل تشغيل يدوي؛ احذف التضاريس السابقة قبل إعادة التوليد لتجنب تراكمها.
- لم يتم تشغيل الحزمة داخل Unity في هذه البيئة، لذلك يلزم اختبارها داخل مشروعك قبل اعتمادها.
- الأداء يعتمد على عدد العناصر ودقة التضاريس وإعدادات المشروع والمنصة.

## العمل من الهاتف
يمكنك تنزيل ZIP والاحتفاظ به أو نقل الملفات إلى مشروعك. لكن Unity Editor الرسمي لا يعمل على Android؛ إنشاء APK/IPA واختبار المشروع يحتاج إلى كمبيوتر أو خدمة بناء سحابية متوافقة.
