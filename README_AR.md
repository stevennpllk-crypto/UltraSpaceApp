# NOVA ENGINE 6 — Unified Release v1.0.0

## ما هذا الإصدار؟
هذا إصدار موحّد يجمع أنظمة NOVA ENGINE 6 في حزمة واحدة. NOVA ENGINE 6 طبقة أنظمة وأدوات تعمل فوق Unity 6، وليست بديلاً عن Unity Editor أو محركاً مستقلاً.

## الحزم المضمنة
- `com.nova.engine6.core` — الأساس والأنظمة المركزية (اعتماد إصدار Core Systems v0.2.0، وهو الأحدث من v0.1.0).
- `com.nova.engine6.graphics` — أنظمة الرسوميات.
- `com.nova.engine6.physics` — أدوات الفيزياء.
- `com.nova.engine6.ai` — أنظمة الذكاء الاصطناعي الأساسية.
- `com.nova.engine6.world` — أنظمة العالم والتوليد.
- `com.nova.engine6.audio` — أنظمة الصوت.
- `com.nova.engine6.input` — أنظمة الإدخال والتحكم.
- `com.nova.engine6.ui` — الواجهات وHUD.

## التثبيت
1. أنشئ مشروعاً جديداً في Unity 6 (6000.x).
2. فك ضغط هذا الإصدار.
3. انسخ المجلدات الموجودة داخل `Packages/` إلى مجلد `Packages/` في مشروعك.
4. افتح المشروع وانتظر استيراد الحزم.
5. راجع ملف `README_AR.md` داخل كل حزمة، وأضف المكونات إلى المشاهد واربط مراجع Inspector المطلوبة.

## التوافق والاعتماديات
- تستهدف الحزم Unity 6 (`6000.0`).
- بعض الأنظمة تعتمد على وحدات Unity القياسية مثل Physics وAudio وUI (UGUI).
- قد تحتاج إلى ضبط Active Input Handling إلى `Both` أو `Input Manager (Old)` لاستخدام مكونات الإدخال القديمة.
- هذه الحزم لا تنشئ مشروع لعبة متكاملاً تلقائياً؛ يجب إعداد المشاهد والموارد والروابط داخل Unity.

## حدود الإصدار
- يتضمن الإصدار 8 حزم Unity، جُمعت من 9 أرشيفات سابقة؛ إصدار Core Systems v0.2.0 هو المعتمد بدلاً من Core Foundation v0.1.0.
- تم تجميع ملفات الحزم دون ادعاء إجراء دمج برمجي أو اختبار تكاملي.
- لم يتم تشغيل Unity Editor أو إجراء Compile/Build في هذه البيئة.
- لذلك فهذا إصدار موحّد للملفات والتنظيم، وليس إصداراً مثبتاً نجاح تجميعه أو جاهزاً للنشر.
- لا يوجد APK أو IPA ضمن هذه الحزمة.

## العمل من الهاتف
يمكن تنزيل الحزمة وإدارة ملفاتها من الهاتف، لكن Unity Editor الرسمي لا يعمل على Android. اختبار السكربتات وبناء APK/IPA يحتاجان إلى كمبيوتر أو خدمة بناء سحابية متوافقة.


## الإصدار 1.1.0 - أدوات المطور
أضيفت حزمة `com.nova.engine6.developertools` وتحتوي على نافذة فحص أولي:
`Tools > NOVA > Project Validator`

هذه الأداة تعمل داخل Unity Editor فقط. راجع تقرير `BUILD_STATUS.txt` لمعرفة ما تم التحقق منه وما لم يتم.


## الإصدار 1.2.0 - Project Setup Wizard
أضيفت نافذة `Tools > NOVA > Project Setup Wizard` لإنشاء هيكل مجلدات داخل Assets، مع قائمة تحقق لإعداد Android. لا تنشئ الأداة APK تلقائياً.
